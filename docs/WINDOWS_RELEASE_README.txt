Excel Data Toolbox AI 9.9.1

1. Extract the entire ZIP archive.
2. Run BiaogeKuaichuAI.exe from the extracted folder.
3. The application opens a local page on http://127.0.0.1:8501/ (or the next available port).
4. Select "试用电商订单对账" for a synthetic reconciliation and download the Excel result.
   For sales analysis, select "加载演示数据" and run the pre-filled command.
   Both demonstrations work without an API key.

The application stores tasks under the current user's local application data directory.
It does not overwrite source workbooks. DeepSeek configuration is optional and is not included in this archive.
