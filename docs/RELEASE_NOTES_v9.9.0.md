# Excel Data Toolbox AI v9.9.0

First public open-source release.

## Highlights

- Natural-language Excel workflows
- Local deterministic execution
- Excel cleaning, reconciliation, and business analysis
- Native charts and management reports
- Output validation and source-file protection
- Optional DeepSeek integration
- Windows packaged build

## Download

Windows users: download `Excel-Data-Toolbox-AI-Windows-x64.zip`, extract it, and run `BiaogeKuaichuAI.exe`.

Developers can install from source using the commands in [README.md](../README.md#run-from-source).

## Notes

- The AI provider is optional.
- Original Excel files are not overwritten.
- Do not upload customer secrets or private files to public issues.
