# Excel 数据处理接单与交付 SOP

## 1. 咨询阶段

先让买家提供以下六项信息，不要只问“多少行”：

1. 文件格式、文件数、工作表数、数据行数。
2. 当前数据是什么样，最终希望得到什么结果。
3. 用于去重、匹配或比对的关键字段。
4. 是否要保留公式、格式、图表、宏；首版工具不承诺复杂格式保真。
5. 截止时间与交付格式。
6. 是否包含个人或公司敏感数据；先索要 20 行脱敏样例。

建议直接回复：

> 您好，请先发：①文件格式和 Excel/WPS 版本；②大约多少行、多少个表；③需要得到什么结果；④期望结果示例；⑤截止时间；⑥是否含个人或公司敏感数据，请先脱敏。可先提供 20 行脱敏样例，我确认范围、价格、时效和修改次数后再下单。

## 2. 报价与确认

报价按“文件数 + 行数 + 数据结构数量 + 规则数 + 业务口径 + 人工确认量 + 交付物 + 时限”综合确定。对账、看板、自动化工具不能按普通去重价格报价。

成交前在闲鱼站内写清：

- 输入文件、工作表与大致行数；
- 具体处理规则和关键字段；
- 交付文件格式；
- 总价、完成时间；
- 原需求范围内免费修改次数；
- 新增需求需重新评估报价；
- 买家确认拥有数据处理授权；
- 默认验收后 7 天删除本单文件。

## 3. 建立任务

- 任务号格式：`YYYYMMDD-001`。
- 原始文件保存为只读副本，全程不覆盖。
- 文件名建议：`客户简称_任务号_原始文件_01.xlsx`。
- 在“表格快处”中填写任务名并导入数据。
- 先运行“一键智能分析”，保存质量得分、问题清单和需要客户确认的字段口径。

## 4. 小样确认

先处理 20～100 行脱敏样例，并让客户确认：

- 字段名称与顺序；
- 去重保留规则；
- 连接方式与一对一/一对多关系；
- 日期、金额、空值处理方式；
- 汇总统计口径；
- 图表指标、日期粒度、Top N、同比/环比等分析口径；
- 异常值是删除、保留还是只做标记；模糊匹配候选必须由客户确认；
- 交付文件与工作表结构。

## 5. 全量处理与质检

至少完成以下检查：

- 处理前后行数、列数变化合理；
- 唯一键仍保持唯一；
- 连接后行数没有异常膨胀；
- 金额、数量、订单数等关键合计与预期一致；
- 空值数、重复值数和转换失败数已记录；
- 随机抽查不少于 10 条；
- 敏感字段已脱敏后再截屏；
- CSV/Excel 文本公式注入防护已开启。
- 质量体检问题已经逐项说明，异常值与模糊匹配没有被静默修改；
- 图表合计、占比和原始数据能相互核对，相关性没有被表述成因果关系；
- 业务结论区分“程序计算结果”和“客户确认后的业务判断”。

## 6. 交付包

建议包含：

- `客户简称_任务号_处理结果.xlsx`
- `客户简称_任务号_异常数据.xlsx`（如有）
- `客户简称_任务号_质量与分析报告.xlsx`
- 结果文件中的“处理摘要”工作表
- 3～5 张脱敏图表或独立看板文件（看板套餐）
- 可重复运行的规则/小工具与使用说明（自动化套餐）

交付说明应写明：已完成的规则、行数变化、异常数据、需要客户复核的项目以及免费修改范围。

## 7. 验收与删除

- 请客户先备份并抽查结果。
- 原需求范围内按约定修改；新增口径重新报价。
- 客户验收后，在工具中点击“清空本任务”。
- 默认在验收后 7 天删除本地原文件和结果；若客户要求更短周期，以站内约定为准。
- 未经客户书面/站内明确许可，不把真实文件、截图或字段值作为案例。

## 不接范围

- 考试、作业、竞赛代做；
- 论文或科研数据造假；
- 伪造工资流水、发票、票据、证明或经营数据；
- 破解 Excel 密码、绕过访问权限；
- 未经授权处理、爬取或买卖个人信息；
- 任何违法、欺诈或侵权用途。
