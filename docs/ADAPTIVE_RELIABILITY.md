# 通用分析可靠性与验收

本轮是通用执行底座改造，不是又增加一个行业模板。这里只描述当前已实现能力，不能理解为“任意 Excel 都能自动做出正确商业决策”。

## 处理链路

需求 → 事实域识别 → 逐指标语义契约 → 安全参数校验 → 独立事实域计算 → 数值验收 → Excel 写入并重读验收。

- `primary_index` 保留为兼容的明细展示锚点。指标、排名、趋势分别绑定事实表索引，不再由主表控制全部计算。
- 候选关联显示基数、左右行覆盖率和左右唯一键覆盖率。多对多、空键、无交集直接标记阻断；候选关系不会自动执行连接。
- 当前通用分析不自动把收入表减去采购/费用表计算净利润，也不自动把退款发生月当成订单归属月。
- 行业专用流程继续使用已有明确规则，本轮没有改写餐饮、电商、库存、人员等专用插件。

## 语义契约

每个指标有来源、聚合方式、单位、候选物理键、时间字段、样本范围、分子分母、数值有效性、问题及版本。

状态含义：

| 状态 | 含义 |
| --- | --- |
| inferred | 从本地字段和数值证据推断，可以按披露的源记录范围统计；不是已确认会计政策 |
| unavailable | 当前条件下不可计算，显示原因，不填零、不输出部分样本总额 |
| available（问题证据） | 支持该主题的有限源表统计，不代表所有经营问题都得到解答 |
| partial（问题证据） | 只有部分证据；明确缺口和结论边界 |

通用模块会阻断以下情况：

- 未知数值聚合语义、单价/均值/效率指标直接求和；
- 缺失、不可解析、无穷数值；
- 发现完全重复记录但没有去重业务规则；
- 多币种、多数量单位、单位缺失或比例分子分母数量级不一致；
- 多个时间字段且未确认分析口径；
- 比例的分子分母样本不完整或分母合计非正；
- 余额没有唯一日期、期末实体键冲突、最新时点没有覆盖全部实体；
- 存在状态字段但有效记录规则未明确。

千分位、人民币符号及单元格百分号可以解析，但不会删除 `kg`、`箱`、`$` 等标记来假装完成换算。百分号按每个单元格处理，不按多数投票缩放整列。`万元`字段保留万元口径，不把数值原样标成元。

## 原记录保护

- 同构字段不代表可合并，同一行不代表重复交易。因此通用报告不再默认合并同构表、删除相同记录。
- 清洗、去重、过滤和合并仍可通过现有结构化操作执行，但必须有明确参数；冲突和排除记录由执行审计保留。
- 通用报告的“主数据分析”仅展示锚点。“事实域明细”保留全部已识别事实表、源表和数据记录位置，不对异构明细联合求和。
- 源 Excel 不被覆盖；本轮测试全部使用合成数据，不公开客户文件。

## 输出变化

通用报告现为 12 张表：原有 9 张，增加“语义契约”“问题与证据”“事实域明细”。服务器按实际生成清单导出，避免新增核验表被固定九表清单遗漏。

- 排名占比使用全部类别合计，不使用截断后的 Top N 合计。
- 结构图保留“其他类别”，负值或没有正合计时不生成结构图。
- 趋势不会把不同单位的指标放在同一纵轴；图表标题标明事实来源。
- 多事实表分别计算、分别显示期间，不自动分摊成本或退款。

## 重复验收

在仓库根目录执行（Windows 虚拟环境）：

```powershell
.\.venv\Scripts\python.exe -m pytest -q -o cache_dir=.tmp/pytest-cache
.\.venv\Scripts\python.exe -m ruff check . --select E9,F63,F7,F82
.\.venv\Scripts\python.exe scripts/check_secrets.py
.\.venv\Scripts\python.exe scripts/check_docs_links.py
```

新增的 `workflow_evaluation.py` 可接收本地、mock 或远程规划器及 Golden 数值期望，依次验证：合法计划、所需操作、实际结果值、源数据不变、原生图表及重读 Excel 完整性。数值或图表失败不会发布新的交付文件。

`tests/test_workflow_evaluation.py` 同时覆盖 mock 规划器和三个不同中文表述的实际本地服务器链路。mock 测试不代表 DeepSeek 理解能力通过。远程模型未在本轮调用。

## 尚未解决的边界

- 字段名称和日期唯一性仍只是推断；“同名收入”不必然是同一收入确认政策。
- 关系图当前用于证据检查、来源绑定与阻断风险，不是任意跨事实自动分摊引擎。
- 未增加业务口径确认 UI、客户级持久化规则或 AI 自动批准口径；这些是后续迭代，不应宣称已经完成。
- 不完整数据只能给出核验要求；不能从缺少成本、库存单位或回款时间的数据保证企业净利润、积压判定正确。
- 本轮没有对所有历史客户文件重新跑 Golden 验收；现有测试中缺失文件的场景会明确跳过。
- 自动重读验证不是人工 Excel/WPS 视觉审美验收，不能据此宣称所有界面都完美。

新增业务需求应先补充合成场景及标准答案，通过同一验收链路验证；不要为单个客户再硬编码一套数字结论。
