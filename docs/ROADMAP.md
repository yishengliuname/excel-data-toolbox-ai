# 路线图

路线图用于协调贡献，不代表发布日期承诺。

## P0：可信交付

- [ ] 为跨表连接增加粒度合同和基数爆炸拦截的更多测试。
- [ ] 为所有专业报告统一事实/推断/建议/人工核验数据结构。
- [ ] 扩展 Excel 图表在桌面 Excel、WPS 和 LibreOffice 的兼容测试。
- [ ] 增加任务级审计包和可复现运行清单。

## P1：通用分析能力

- [ ] 从“单主事实表”升级为多事实域证据图，不直接拼接不同粒度表。
- [ ] 增加可配置指标公式目录和口径版本管理。
- [ ] 扩展教育、医疗运营、项目交付等无客户专用代码的领域包。
- [ ] 建立公开、完全虚构的跨行业基准测试集。

## P2：体验与生态

- [ ] 国际化界面和英文报告模板。
- [ ] 可插拔模型适配器，保留同一安全计划协议。
- [ ] 报告主题、颜色和图表布局的无代码配置。
- [ ] 插件式只读数据源连接器。

欢迎认领已有 Issue。较大功能请先提交 Feature Request，明确安全边界、数据口径和验收样例。
