# 表格快处 Pro｜第二版产品调研与路线图

更新时间：2026-08-21

## 结论先行

基础去重、合并、拆分已经是低价同质化能力。更容易让客户付费的不是“按钮更多”，而是以下三类结果：

1. **降低风险**：对账差异、异常清单、质量评分、验收证据和可追溯处理记录。
2. **支持决策**：趋势、贡献、排名、相关性、客户分群、图表和简明结论。
3. **长期省时间**：可复用处理方案、文件夹批处理、一键刷新和可重复运行的小工具。

因此产品主流程应从“导入 → 清洗 → 导出”，升级为：

> 需求与验收 → 导入体检 → 清洗关联 → 对账分析 → 质量验收 → 打包交付

## 公开市场信号

公开挂牌可见的价格结构大致为：

- 基础合并、去重等单项任务：低价竞争明显。
- 清洗、对账和多表处理：通常按文件数、行数、规则数与修改次数分档。
- 自动报表、经营看板、可重复运行工具：价格明显高于一次性处理。

其中两类挂牌结构较有参考价值：

- 数据分析服务以“清洗文件 + 摘要”“多张图表 + 结论”“完整报告 + 代码 + 业务建议”逐级增加交付物。
- 动态报表服务以“自动读取文件夹、规则清洗、联动筛选、指标预警、一键刷新、使用说明”形成高档套餐。

挂牌价不能视为真实成交均价，只能用于识别客户愿意为哪些能力支付溢价。

## GitHub 与成熟产品启发

### 一键数据体检

`fg-data-profiling`（原 `ydata-profiling`）覆盖字段类型、缺失、重复、异常、偏态、相关性、时间序列、两版数据比较和 HTML/JSON 报告。这说明“自动发现问题并生成报告”本身就是可交付产品。

当前表格快处运行在 pandas 3.0.1，而该项目目前要求 pandas `<3.0`，因此第二版采用轻量自研分析器，避免降级破坏现有环境。

- [fg-data-profiling](https://github.com/Data-Centric-AI-Community/fg-data-profiling)
- [依赖声明](https://github.com/Data-Centric-AI-Community/fg-data-profiling/blob/develop/pyproject.toml)

### 相似值聚类与可复用历史

OpenRefine 的高价值能力是相似文本聚类、实体对齐、分面筛选、撤销重做和把操作历史应用到新数据。可借鉴为“供应商/客户/商品名称归一”和“下个月换文件一键重跑”。

- [OpenRefine](https://github.com/OpenRefine/OpenRefine)
- [聚类与单元格编辑](https://openrefine.org/docs/manual/cellediting)
- [撤销与历史](https://openrefine.org/docs/manual/running/)

### 处理步骤与差异预览

Microsoft Data Wrangler 将字段统计、处理前后差异、步骤历史和代码导出放在同一流程中，值得借鉴交互逻辑。其许可证不适合复制代码并组合进独立产品，因此只借鉴产品思想。

- [Data Wrangler 官方文档](https://code.visualstudio.com/docs/datascience/data-wrangler)
- [许可证](https://github.com/microsoft/vscode-data-wrangler/blob/main/LICENSE)

### 可视化与大文件

- Plotly 提供大量交互图和独立 HTML 输出，适合未来的离线看板交付。[Plotly.js](https://github.com/plotly/plotly.js/)
- PyGWalker 展示了拖拽式探索、过滤、下钻和本地计算的方向。[PyGWalker](https://github.com/Kanaries/pygwalker)
- DuckDB 适合多文件、CSV/Parquet 和本地 SQL 分析，可用于后续百万行版本。[DuckDB](https://github.com/duckdb/duckdb)
- Polars 的 Lazy API 与 Streaming 适合更大数据阶段。[Polars Lazy API](https://docs.pola.rs/user-guide/concepts/lazy-api/)

## 功能路线

### P0：立即形成可收费交付

- 一键数据体检：质量分、缺失、重复、常量、高基数、异常、相关性和问题建议。
- 自助可视化：柱状图、趋势图、占比图、直方图和散点图。
- 异常值检测与异常明细。
- 交叉透视、分类贡献、趋势聚合和 RFM 客户价值分群。
- 新旧表精确对账，输出新增、删除、修改、未变化和重复键。
- 分析交付包：原数据、质量概览、问题清单、描述统计、相关性和异常明细。
- 相似名称候选组和模糊匹配，低置信度必须人工确认。

### P1：明显提高客单价

- 保存/导入处理方案，换一批文件一键重跑。
- 质量验收规则：非空、唯一、范围、枚举、正则、合计和关联完整性。
- 金额容差、日期窗口、一对多与拆单/合单对账。
- 同比、环比、移动平均、ABC 分类和库存预警。
- 交互 HTML 看板、图片/PDF 报告和 Excel 图表交付。
- 文件夹批处理和字段映射模板。

### P2：成熟后扩展

- DuckDB/Polars 大数据引擎。
- 定时任务、月报自动刷新和历史批次趋势。
- 模板样式与常见公式保留。
- 在明确隐私授权后增加自然语言配置规则。

## 建议套餐

| 套餐 | 交付范围 | 建议测试价 |
|---|---|---:|
| 快速清洗包 | 1 文件、≤1 万行、≤3 项规则；结果表 + 处理摘要 | ¥59–99 |
| 标准整理包 | ≤5 文件、≤5 万行、≤8 项规则；结果 + 异常表 + 验收摘要 | ¥199–299 |
| 精准对账包 | 两组数据、≤10 万行；差异分类、金额核验和质检报告 | ¥299–499 |
| 经营分析看板包 | 清洗 + 5–8 个指标/图表 + 3–5 条结论 + 分析报告 | ¥599–899 |
| 一键自动化工具包 | 参数化方案、批量运行、异常报告、说明书与 30 天 Bug 售后 | ¥899–1,999 |
| 月度数据管家 | 固定结构的周期处理、趋势、异常、月报和响应时限 | ¥999–2,999/月 |

实际报价必须同时看文件数、行数、数据结构数量、规则数、业务口径、人工判断量、截止时间、修改范围和交付物，不能只按行数报价。

## 经营边界

- 不把“自动生成”宣传成“百分百正确”；业务结论必须由客户确认口径。
- 模糊匹配、异常检测和相关性只提供候选与证据，不替客户做不可逆的业务判断。
- 不承接考试作业、论文数据造假、流水/票据/证明伪造或未经授权的个人数据处理。
- 开源项目只能在许可证允许的范围使用；第二版不复制 Data Wrangler 代码，也不直接嵌入 Metabase 商业目录。
