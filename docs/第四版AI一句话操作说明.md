# 表格快处 Pro V4｜AI 一句话完成：从 0 开始

## 1. 它到底做什么

V4 把一段中文业务需求转换成程序能理解的严格参数，然后调用本机已有的 Excel 处理能力完成任务。

DeepSeek 只负责“理解需求和编排步骤”，不直接读取文件、不执行代码、不碰你的磁盘。真正的清洗、对账、分析和导出都由本机白名单引擎完成。

流程固定为：

`自然语言 → DeepSeek JSON 计划 → 本地严格校验 → 隔离预演 → 人工确认 → 本地执行 → 人工核验 → 导出`

### 随便一句口语，程序怎样变成操作

你不需要先学会写参数，也不必把需求写成程序术语。完整链路是：

`随便一句业务口语 → DeepSeek 整理成标准业务话术 → 转为白名单参数计划 → 本地校验与预演 → 你确认 → 本机执行`

- “标准业务话术”是页面里的计划摘要：它把“收拾一下”“差几分钱算上”“名字差不多”等口语，明确成数据表、字段、规则、阈值和输出。
- “参数计划”只包含本程序允许的操作及参数，例如匹配键、金额容差、日期窗口和质量规则；DeepSeek 本身不能运行代码或直接修改表格。
- 如果缺少会改变结果的决定性条件，例如不知道哪列是订单号、金额容差是多少、两张同名表该选哪张，程序会显示“需要补充”并提问，绝不会自行猜测。
- 计划生成后不会自动执行。只有你检查预演结果、勾选人工确认并点击“确认并执行”，本机引擎才会处理数据。
- DeepSeek API Key 只用于本次 HTTPS 请求的内存过程，不写入任务、计划、日志、浏览器存储或文件，页面刷新后即清空。

复杂口语示例：

> 把上半年各门店那几张乱七八糟的订单先收拾干净，重复的别算两遍；客户名字相似度八成八以上的尽量和客户档案对上。再跟银行回款核一下，金额差五分钱以内、晚七天到账都可以，但一笔钱拆成几笔、重复流水或者拿不准的都别替我决定。最后看看各区域每月完成得怎么样，找出特别离谱的订单和最有价值的客户，给我能交付的结果表，原表别动。

DeepSeek 整理后的标准业务话术示例：

> 对所选门店订单表先清理文本空格并按订单号去重，检查订单号唯一、客户 ID/区域/订单日期非空及金额非负；将订单表纵向合并。客户名称按 88% 相似度与客户主数据匹配，歧义结果进入人工核验。合并订单与银行回款按订单号对账，金额容差 0.05 元、日期容差 7 天，重复键及一对多/多对一候选只进入人工核验。随后按区域和月份汇总销售额与订单数，生成金额 IQR 异常明细和客户 RFM 分群结果。所有结果另存为新表，不覆盖输入表。

随后页面会列出对应的清洗、验收、合并、模糊匹配、容差对账、汇总、异常检测和 RFM 参数步骤。这里的 `88%`、`0.05 元`、`7 天` 都是决定性条件；如果原口语没有提供且无法从明确字段关系判断，程序会先追问，不会擅自补值。

## 2. 第一次使用

1. 双击项目目录里的 `启动表格快处.cmd`，不要关闭弹出的启动窗口。
2. 浏览器打开 `http://127.0.0.1:8501` 后，先导入 `.xlsx` 或 `.csv`。
3. 在“AI 一句话完成”左侧勾选允许 AI 使用的数据表。只选本次任务真正需要的表。
4. 在 DeepSeek 密钥框粘贴 API Key。密钥只在当前密码框和这一次规划请求的内存中存在，刷新页面会清空。
5. 普通任务选 `deepseek-v4-flash`；多表对账、十步以上分析或复杂口径选 `deepseek-v4-pro`。
6. 用一段话写清楚输入表、关键字段、规则、容差和期望结果。
7. 点击“仅生成计划”。这一步不会把结果写入任务。
8. 核对表范围、每个步骤、字段、参数、假设和警告。若显示“需要补充”，修改需求后重新规划；若显示“不支持”，程序不会执行。
9. 确认无误后勾选人工确认，再点击“确认并执行”。
10. 查看新增结果表与“人工核验中心”，最后用“脱敏导出”生成交付包。

## 3. 一段好需求怎么写

建议按这个句式：

> 对【哪些表】，先做【清洗规则】，再按【匹配键】执行【业务操作】，使用【金额/日期/相似度等阈值】，分别输出【结果表】，遇到【哪些歧义】只进入人工核验，不要覆盖原表。

高难度示例：

> 把订单明细去掉完全重复行并清理文本空格；检查订单号唯一、客户 ID 和区域非空、数量 1–100、折扣率 0–0.3；按客户名称原值与客户主数据做 88% 模糊匹配；订单和回款按订单号对账，金额容差 0.05 元、日期窗口 7 天，拆分回款不要强行自动通过；然后生成区域月份销售汇总、区域×渠道销售透视、订单金额 IQR 异常明细、客户 RFM 分群，并把月度区域汇总与目标表按区域月份匹配。任何歧义、重复流水、待认领款和容差外差异都送人工核验，不要改原表；最后生成手机号、邮箱、客户名称脱敏副本。

## 4. 当前可自动完成的任务

- 智能清洗、空白规范、完全重复或关键字段去重、类型识别
- 字段选择、重命名、排序、替换、筛选和安全配方
- 多表纵向追加、精确连接、查找匹配
- 相似名称聚类、主数据模糊匹配
- 非空、唯一、范围、正则、允许值等质量验收
- 多键、金额容差、日期窗口、重复键和拆分候选对账
- 描述统计、相关性、IQR/Z-Score 异常检测
- 日/周/月/季/年趋势、分组汇总、分类贡献、交叉透视
- 新旧表新增/删除/修改比对、RFM 客户价值分群
- 手机号、邮箱、姓名、证件号和通用字段脱敏
- 按字段或固定行数拆分数据

## 5. 程序会拒绝什么

- VBA/宏执行或编辑、破解文件密码
- 任意 Python、SQL、Shell、浏览器自动化、文件路径或外部联网指令
- OCR、PDF 转 Excel，以及要求无损保留复杂图表/透视缓存/切片器的任务
- 伪造流水、票据、证明、考试或论文数据
- 缺少会改变结果的关键字段、匹配键、容差或业务口径

缺信息时状态为 `clarification`，程序会提出问题；能力越界时状态为 `unsupported`，不会生成执行凭证。

## 6. 隐私与密钥

- 普通本机功能不连接 DeepSeek。
- AI 规划默认发送：需求文字、所选表名、字段名、数据类型、缺失/唯一计数和行列规模。
- 默认不发送：单元格原值、预览行、原文件、处理结果、客户附件。
- API Key 不进入请求正文、任务、配方、日志、localStorage、sessionStorage 或导出文件。
- 规划凭证 15 分钟失效，只能使用一次；任务清空、表范围变化或执行失败后必须重新规划。
- 不要把身份证号、银行卡号、客户明细或 API Key 写进“需求描述”。

凡是曾经发到聊天窗口、群聊或截图里的密钥，都建议到 DeepSeek 控制台重新生成，再只粘贴到本机密码框。

## 7. 常见错误

- `API Key 无效或已失效`：重新复制或在控制台生成密钥。
- `账户余额不足`：充值后重试。
- `请求过于频繁`：稍等再试，或减少并发。
- `返回空计划/输出被截断`：换 `deepseek-v4-pro`，并把需求拆成两次。
- `本地安全校验失败`：模型使用了不存在的字段或不支持的参数；按提示改写需求。
- `计划已过期/已使用`：重新点“仅生成计划”。
- `执行期间任务发生变化`：重新选择最新数据表并规划。
