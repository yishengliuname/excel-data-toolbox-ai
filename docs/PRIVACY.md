# 隐私与数据处理

## 默认行为

- 应用只监听 `127.0.0.1`，数据处理在本机完成。
- 不启用 AI 时，不会向 DeepSeek 发送请求。
- 启用 AI 路由时，默认发送需求文本以及所选表的结构目录，不发送完整单元格原值。
- API Key 从 Windows DPAPI、进程环境变量或本机 `.env` 读取，不返回浏览器，不写入计划、日志或 Excel。
- 每个任务拥有独立目录；历史输出不作为新任务输入。

## 绝不应进入公开仓库的内容

- `.env`、API Key、密码、令牌、私钥、数据库连接字符串；
- 客户 Excel/CSV/PDF/图片、截图、导出报告、日志和 SQLite 文件；
- 姓名、手机号、身份证号、银行卡号、订单号等真实业务标识；
- 未获授权的第三方模板、数据或图片。

仓库通过 `.gitignore`、`scripts/check_secrets.py` 和 GitHub Secret Scanning 形成三层保护。秘密扫描不能替代撤销密钥：如果密钥曾公开，必须立即轮换。

## 贡献者测试数据

测试数据应由测试代码现场构造，使用明显虚构的名称和金额。确需提交静态夹具时，应先获得维护者批准并提供来源、许可证和隐私证明。

## 专业责任

程序提供数据整理和辅助分析，不构成财务、税务、法律、审计、人事或投资建议。涉及重大经营决策的结果必须由具备权限和专业资格的人复核。
