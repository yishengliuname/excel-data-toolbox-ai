# Repeatable product demo

This demo is designed for a first-time user, a release check, or a 20-second product recording. It uses only data generated by the application.

## Demo dataset

1. Start the local app.
2. Open `http://127.0.0.1:8501/`.
3. Select **加载演示数据**.

The application resets the current demo task and creates exactly one deterministic, fictional sales table. Do not substitute a customer workbook when recording public assets.

## Demo request

Use this single request:

> Analyze revenue, cost, and profit by region and product. Find low-margin items, create a monthly trend chart, and export a management-ready workbook. Do not modify the original file.

The Chinese equivalent is:

> 按地区和产品分析销售额、成本和利润，找出低毛利商品，生成月度趋势图，并导出老板可以直接看的工作簿。不要修改原始文件。

## Expected output

The exact number of report sheets may change as validation improves, but the demo must show all of the following:

- the fictional source table and its row/column profile;
- revenue, cost, profit, and margin evidence where the fields support them;
- a monthly trend;
- product or region contribution;
- low-margin or data-quality warnings;
- at least one native Excel chart;
- a downloadable workbook that reopens successfully;
- no change to the source table.

If one of these outcomes is missing, treat the demo as failed and open a reproducible bug report.

## Recording guide

Record at 1440 × 900 or 1920 × 1080. Keep the final GIF between 15 and 30 seconds.

1. **0–3 s:** show the landing page and local-only status.
2. **3–6 s:** select **加载演示数据**.
3. **6–10 s:** paste the demo request.
4. **10–14 s:** show the structured plan and validation state.
5. **14–19 s:** show KPI, warning, and chart results.
6. **19–23 s:** export the workbook.
7. **23–28 s:** open the workbook and show the native chart plus audit sheet.

Keep zoom at 100–110%, avoid rapid scrolling, and crop browser chrome only after confirming that the local URL and application context remain clear.

## Privacy checklist

- [ ] Synthetic demo data only.
- [ ] No API key, `.env`, token, or account page is visible.
- [ ] No customer file, customer name, phone number, address, or order identifier is visible.
- [ ] No private local path or user profile name is visible.
- [ ] Browser history, bookmarks, notifications, and unrelated tabs are hidden.
- [ ] The exported workbook contains only synthetic values.
