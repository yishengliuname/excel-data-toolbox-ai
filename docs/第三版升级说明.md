# 表格快处 Pro V3｜升级说明

## 这次升级解决什么

V3 的目标不是继续堆“清洗按钮”，而是形成可以收费交付的完整链路：规则可复用、结果可解释、疑点可复核、交付可验收。

## 五条核心工作流

### 1. 保存方案并复跑

- 支持清洗、替换、字段选择/重命名/排序、空值填充、去重、筛选和分组汇总。
- 方案只保存声明式 JSON 规则，不允许 Python 表达式、脚本、导入路径或任意函数。
- “试运行”会在副本上完整执行并显示行列变化，不写入当前任务；确认后再正式生成结果表。
- 方案持久化在本机 `user_data/recipes/`，不保存客户文件、原始单元格内容或预览。

### 2. 质量验收

- 可配置非空、唯一、数值范围、正则格式和允许值规则。
- 后端还支持数值类型、日期、跨列比较等高级规则，便于后续扩展界面。
- 每次运行生成“规则汇总”和“失败明细”两张表；失败记录自动进入人工核验中心。

### 3. 高级对账

- 左右表可配置多列匹配键、金额字段、可选日期字段、金额容差和日期容差。
- 金额使用 Decimal 处理，避免普通浮点数用于财务对账时产生不可解释的小数误差。
- 自动输出：对账摘要、自动匹配、金额差异、日期差异、待人工确认、左侧独有、右侧独有、重复键隔离。
- 重复键、冲突键、近似候选和 1:2 / 2:1 拆分建议不会静默确认，只进入人工复核。

### 4. 人工核验中心

- 汇总质量失败、异常值、相似名称、模糊匹配和高级对账疑点。
- 支持批量接受、拒绝、恢复待确认和备注，并显示待确认/已接受/已拒绝数量。
- 核验状态存在于本次本地任务内；清空任务后随临时数据一并清除。

### 5. 专业交付

- 上传 `.xlsx` 时先检测公式、外部链接、宏、图表、透视表、切片器、隐藏工作表、合并单元格和批注，并明确提示保留边界。
- 专业 Excel 交付包包含处理摘要与验收清单；所有工作表统一表头、冻结首行、启用筛选、优化列宽和打印设置。
- 默认防止以 `= + - @` 开头的文本触发表格公式；真正的负数数值不受影响。
- 任务支持撤销和重做，处理函数不会覆盖原表。

## 推荐接单流程

1. 客户先提供 20 行脱敏样例和期望结果。
2. 建立任务并导入样例，查看工作簿预检和数据体检。
3. 配置验收规则、对账口径或处理方案，先试运行。
4. 客户确认小样后执行全量，逐项处理人工核验中心。
5. 导出专业 V3 交付包，随机抽查关键合计和差异记录。
6. 客户验收后清空任务，并按约定删除客户文件。

## 明确边界

- 当前支持 `.xlsx` 和 `.csv`；不执行宏、不破解密码、不重新计算 Excel 公式。
- 新导出文件以数据正确和验收证据为目标，不保证保留原工作簿的复杂图表、切片器、透视表或排版。
- 自动匹配结果仍需按业务口径抽查；规则分数是可解释的确定性分数，不是统计概率。
- 当前不包含 OCR / PDF 转 Excel。后续若增加，应独立做中文表格识别、置信度和人工复核，不能把识别结果直接当成正确数据。
